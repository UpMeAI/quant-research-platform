## E1. 半凯利：写出算式和输入

1. 「半凯利」块的结论行之前，加一行算式。所有值都取自结果文件的 `p`、`p_ci`、`b`、`b_ci`、`f_star`、`f_half`：
   - 先写公式：凯利比例 f\* = p − (1 − p) ÷ b，p 为样本外胜率，b 为赔率。
   - 再写代入下沿的结果，例如「按保守下沿 p = 24.1%、b = 1.74，f\* = −19.6%」。
   - 最后一句：「f\* ≤ 0 → 半凯利 = 0：长期看下注越多亏得越多，不支持按凯利加仓」。
2. 再加一行说明「这里的 p、b 与上面『胜率与赔率』表样本外、生产相位、基础成本那一行相同」，指明数据来源。不另算点估计的 f\*。
3. 「固定每笔风险」的路径区间和跌破地板的概率照旧显示，标签写明「重抽样路径，不是预测」。
