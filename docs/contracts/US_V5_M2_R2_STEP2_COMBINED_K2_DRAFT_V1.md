### 1.3 运行前的判定算术（不是预测）

- 若配对 g 的 SE 约等于 0.0532，则 L_g > 0 ⇔ g_配对 > 0.1044。

  - **全部实现扣减合计 < 0.041 /年** → OOS 判「有支持证据」；
  - 扣减 ≥ 0.041 → 「证据不足」；
  - U_g ≤ 0 要求扣减超过天花板本身，在这段 OOS 上算术上几乎不可能。
- 可以先估的两项扣减（只用封存值，量级，不进判定）：

- 所以 OOS 的结局取决于这两项未知扣减是否小于约 0.016 /年。这是同一段数据上的算术，不是独立检验；这就是 §0 把它标为「受选择影响」的原因。

### 1.4 前向需要多久

- 假设前向的 SE 按 √(年数) 缩放：SE(T) ≈ 0.0532 × √(3.79 / T)。
- 要以 80% 功效看见天花板大小的效应（0.145），需要 T ≥ 3.79 × (0.149 / 0.145)² ≈ **4.0 年**。
- 若真实的长期效应只有 0.03 /年（示意：约 0.6 的停放比例乘以几个百分点的股票风险溢价；不是预测），需要的年数是几十年。
