- **导入时拒绝**（失败关闭，错误码前缀 `M2_ROUND_`）：
  - 档案没有 `m2_rounds` 或没有这一轮：`M2_ROUND_NOT_REGISTERED`；
  - 任一角色文件缺失：`M2_ROUND_FILE_MISSING:<角色>`；sha256 与档案登记不符：`M2_ROUND_FILE_SHA_MISMATCH:<角色>`；旁边有 `.sha256` 文件而内容不符：同上；
  - `baseline_result_id` 不是这条策略当前的 Q0 锁（替代链最后一把）：`M2_ROUND_BASELINE_NOT_CURRENT`；QS 文件 `identity.baseline_lock` / `baseline_sha256` 与之不符：`M2_ROUND_BASELINE_MISMATCH`；
  - 选择结果与档案不一致（第 3.3 节）：`M2_ROUND_SELECTION_MISMATCH`；
  - 档案里的固定句与文件数字矛盾（第 4.3 节）：`M2_ROUND_WORDS_CONTRADICT_FILE`；
  - 同一策略同一轮已有锁：`M2_ROUND_ALREADY_LOCKED`；改锁须 `--supersedes <当前 result_id> --defect-ref <…> --reason <…>`（同 Q0）。
- **读的时候**（页面每次）：现场复验每个文件的 sha256。任一不符或缺失 → 这把锁的状态为 `INVALID` / `MISSING`，页面写「第 1 轮封存结果校验未通过」，不写「已冻结」「运行中」。
- `result_id` 选择 D1.1：★(a) `R<轮>-<分解文件 sha256 前 16 位>`（C17 = `R1-229940c24a2246bc`，QS = `R1-c679d4c92c2d67a1`）；(b) 所有角色文件 sha256 排序拼接后再取 sha256 的前 16 位。
