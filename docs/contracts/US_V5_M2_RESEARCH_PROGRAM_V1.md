## 5. 判据细则

### 5.1 三态结论（§6.7）
- 通过：L_R > 0.10 R 且 L_g > 0，覆盖与样本满足。
- 未通过：U_R ≤ 0.10 R，或 U_g ≤ 0。
- 证据不足：其余情况，或覆盖 / 样本不足。
- 先判输入有效性；无效输入不产生经济反证。δ 在运行前冻结于本文件，看见结果后不改。

### 5.2 压力（全部真实运行，不占位）
| 场景 | 做法 |
|---|---|
| 费用 | 15 bps 双边；滑点 ×2 |
| 扫描相位 | 生产相位 ±60 分钟（历史上同一规则两个相位曾为 +1,229 与 −664 USD） |
| 区间重放 | 2020-02-19 → 2020-04-30；2022-01-03 → 2022-10-31 |
| 极端熊市 | 母序列合成 3× 载体重放 2008-09 → 2009-03，标「模拟序列，不是可交易历史」（沿用 US_CORE 10-05 的 F1 融资口径） |
| 风控维度（供 Q4 立题） | 分别去掉 24 h 冷却、把同时持仓 3 → 5、单元风险 60 → 90，各看账户差异；只报不判 |

### 5.3 半凯利研究计算（只展示，不采用）
- 二元固定赔率形式（§7.5）：p = OOS 扣费后净胜率，b = 赔率；f\* = p − (1 − p) / b；半凯利 = f\* / 2。
- 用 p、b 的区间下沿计算；若 OOS 净 R 均值的区间下沿 ≤ 0，半凯利 = 0，页面写「不支持按凯利加仓」。
- 复利结果：在 OOS 按「每笔风险 = 半凯利 × 当前权益」重放，与当前固定 60 USD 并列；给期末资本的 bootstrap 区间、最大回撤、跌破 1800 USD（Rule 1b 40% 线）的条件概率。
- 这是研究量，不是仓位建议；首版保留现行仓位规则。
