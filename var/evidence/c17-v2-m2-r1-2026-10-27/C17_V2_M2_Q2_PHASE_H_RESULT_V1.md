## 4. 读法

1. **K2 关于趋势入场的假设没被 1m 数据支持。** K2 §2.3 预计决定时刻比无条件时刻更难成交（趋势入场价格正朝信号方向走）。
   - 实测入场后下一分钟朝信号方向的漂移均值是 −0.47 bp（95% 区间 −1.10 到 +0.16），决定分钟本身是 −0.39 bp。
   - 入场的穿价率 0.899，在无条件的 0.85–0.91 之内。
   - 所以 p60 高于规划值，SD 低于规划值。
2. EXEC-1 对 t0 吃单，平均省约 1.2 bp。这是 2 bp 费差扣掉 10% 没成交、平均吃亏 6.3 bp 之后的结果。各分组方向一致。止盈出场是例外：样本少，又多在急涨急跌的分钟里，区间跨 0。
3. 前向的 n ≈ 75 时，MDE80 约 1.1–1.3 bp，比 K2 规划的 1.6 bp 灵敏。照这些规划值，X1（S̄ > 0）在 n = 75 时成立的概率约 0.99；X2 的 P95 是 0.021，阈值 0.05。
   - 但 X1 的判据口径是 `QUEUE_FIFO_NO_CANCEL`，窗口是从 :50.496 起的 60 秒，比较对象是实测的 CUR。这里三样都只是近似，结论仍以前向数据为准。
4. CAL 在 Phase H 测不到：没有逐笔数据，就没有吃单滑点。只能等前向记录器。

## 5. 披露

- **Q0 V2 的成交价口径与它自己的标签不一致**：
  - 1,129 个入场的记账价全部等于下一根 1m 的开盘价，而不是 Q0 V2 `cadence` 标签写的「扫描分钟的 1m 收盘」。两者相等的有 523 个，差值最大 4.5 bp。
  - Phase H 按 K2 §2.3 原文，用扫描分钟收盘做挂价。Δ 是两种执行对同一个 P 的差，所以不受这个影响。
  - Q0 V2 的这个标签需要协调会话决定是否勘误。
- 止盈出场的记账价是止盈价（63 个都和分钟收盘不同，最大差 428 bp，出现在急涨急跌的分钟）。按 K2 §3，止盈的决定时刻是 60 秒观测，所以 P 取分钟收盘。
- `APPROX_1M_TOUCH` 很宽松：下一根开盘常常就等于 P。它只当上界用。
- 测不到的（同 K2 §2.3）：
  - 队列位置与撤单；
  - 自己委托对盘口的影响；
  - GTX 被拒；
  - 下单延迟；
  - 费率档；
  - :50.496 的决定按分钟收盘近似；
  - CUR 的 5 秒腿。
