## 6. 采用 / 不采用规则（★ 推荐；冻结后不改，冻结前不看任何前向数据）

- **历史部分只报不判**：§0 与 §3 的数字已经被看过，不作为采用条件。
- **前向窗口**：从 **T_start = 本 K2 的冻结时刻**（协调会话记录）起，到查看时点止。T_start 之前的纸面交易（10-07 → 冻结，含 Q0 里的 10 笔）不进入窗口。
- **影子账本（推出，不另跑）**：
  - 影子 = 纸面账本 `QUICK_SHOT_V3_1000USDT` 中 `entry_time_ms ≥ T_start`、`trade_type = SHORT` 的成交行，用纸面行自己的 `net_pnl` / `net_r`。
  - 纸面 = 同一窗口的全部成交行。两边都只计查看时点已平仓的行；未平仓行数另报。
  - 历史上这样推出的影子覆盖候选 99.6% 的交易（样本外 557 笔中 555 笔）。
  - 漏掉的只有这一种：空单信号因同合约持有多单被 `PER_COIN` 跳过。这些行按 `skip_code` 计数并报出；超过影子笔数的 5% 时，查看前用 Q0 引擎（1h exitWalk、存档 K 线）补算。
- **一次查看**：2027-04-30 与影子平仓满 60 笔，二者取后到者。
  - 若纸面账本在此之前因 A18 前向复盘 FAIL 或 25% 账本止损而停止，就在停止时提前查看，窗口截至停止。
  - 按 2026 年每月 8.6 笔，60 笔约在 2027-05 下旬；按样本外每月 16.4 笔，约在 2027-02。
- **做**（交由 Owner 签字，成为 QS V3 的纸面修订）：四项同时满足。
  1. 影子净 USDT ≥ 纸面净 USDT（同一窗口）。等价于：窗口内纸面多单的净和 ≤ 0（另加跳过行的影响）。
  2. 影子净 USDT > 0。
  3. 影子最大亏损 USDT（已平仓净值曲线，峰到谷）≤ 纸面的 1.10 倍。
  4. 影子单独没有触发 25% 账本止损（自身已平仓净值曲线峰到谷 ≥ 25%），也没有跌到 600（Rule 1b 线）以下。影子平仓 ≥ 100 笔时，还要求 A18 的检验（90% 按周聚类，ISO 周，10,000 次，种子 20261005）给出 U ≥ 0。
- **不做**：任何一项不满足，QS V3 不变。
- 不设「证据不足」中间态（Owner 10-06：只有做 / 不做）；功效限制写在结果里（§4）。
- **与 A18 的关系**：A18 已签的前向复盘（第 100 笔与每个季末；n ≥ 100 且 U < 0 → FAIL → 停止）照旧只作用于纸面账本，本 K2 不改它。若 A18 FAIL 在先：
  - 本规则提前查看。
  - 「做」的意思是：Owner 可以签字，让 QS V3 以「只做空」修订重新开账；不签则 QS V3 维持 A18 的停止。
  - 「不做」则 QS V3 维持停止。
